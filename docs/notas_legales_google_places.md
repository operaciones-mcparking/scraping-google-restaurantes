# Notas de uso responsable de Google Places

Google Places API es una buena fuente para buscar, validar y actualizar información de restaurantes, pero no debe tratarse como una licencia libre para copiar y mantener una base permanente de todo el contenido de Google.

Puntos prácticos:

- Revisa las políticas oficiales de Google Maps Platform antes de usar la base comercialmente.
- Guarda siempre `Fuente` y `Fecha de actualización`.
- Conserva `Place ID`, porque Google indica que este identificador tiene una excepción de almacenamiento.
- Si la base se usará como CRM o para ventas, conviene complementar con datos obtenidos desde fuentes propias o sitios oficiales de cada restaurante.
- Evita usar scraping directo de Google Maps; usa API oficial cuando corresponda.
- Si publicas datos derivados de Places API en una app o sitio, revisa requisitos de atribución y uso de marca Google.

Fuentes oficiales:

- https://developers.google.com/maps/documentation/places/web-service/policies
- https://developers.google.com/maps/documentation/places/web-service/text-search
